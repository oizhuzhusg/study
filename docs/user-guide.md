# Chem Coach 使用说明

## 适合谁使用

这个网页目前先服务 NUSH 初中 2 年级 Chemistry，同时补上 Sec 1 Chemistry foundations。这样做是因为很多 Sec 2 错误表面上发生在 `Precipitation Reactions`，底层却可能是 Sec 1 的 formulae、bonding、equations、particle theory 或实验观察没有完全学稳。它的目标不是单纯刷题，而是按“讲概念 -> 举例 -> 做题 -> 根据答案判断掌握情况 -> 继续加强”的方式学习。

## 日常使用流程

1. 打开网页后先选择 profile。
   `Student` 用于真实学生进度，`Tester` 用于家长测试。两个 profile 的掌握度和练习记录互不覆盖。

2. 在左侧 `Knowledge Points` 选择学习范围。
   可以选择 `Sec 1 Chemistry Foundations`、`Sec 2 Chemistry II`，也可以点某一个具体知识点做针对训练。`Precipitation Reactions` 已经放在 Sec 2 Chemistry II 里面。

3. 先看中间的讲解区。
   `Concept` 是核心概念，`Example` 是例子，`Problem-Solving Steps` 是解题步骤，`Reminder` 是容易忘记的关键点。

4. 在右侧完成题目。
   可以直接输入答案，也可以上传手写答案照片。上传照片后，系统会先识别成文字，学生确认后再提交批改。

5. 点击 `Submit for Grading`。
   系统会给出得分、做得好的地方、缺失点和下一步建议，并更新知识点掌握度。

6. 看掌握度颜色。
   绿色表示基本掌握，黄色表示还在练习，红色表示需要继续加强。下一题会优先围绕薄弱知识点生成。

7. 需要从头开始时点右上角的重启按钮。
   这会清空当前 profile 的本地进度，适合重新做诊断或测试流程。

## 更新版本

网页右上角会显示当前版本号。如果服务器上有新版本，页面顶部会出现更新提示。点击 `Update` 会刷新到最新版本，但不会清空 profile 进度。

## 家长建议

- 平时让孩子使用 `Student`。
- 家长试功能、乱填答案或测试照片上传时使用 `Tester`。
- 不要只看一次题目的分数，更要看哪些知识点长期是黄色或红色。
- 如果孩子连续在同一个知识点出错，先回到讲解区，让他用自己的话解释概念，再继续做题。

## 当前范围

当前 Sec 1 foundation 知识点包括：

- Experimental chemistry
- Kinetic theory
- Ions and charges
- Chemical bonding
- Formulae
- Balancing equations
- Acid-base basics
- Observation and inference
- Sec 1 gap diagnosis

当前 Sec 2 Chemistry II 知识点包括：

- Reaction type diagnosis
- What a precipitate is
- Predicting whether a precipitate forms
- Writing chemical formulae
- Balancing precipitation equations
- Adding state symbols
- Identifying spectator ions
- Writing net ionic equations
- Using observations to infer ions
- Writing complete explanations
- Acid-base reactions
- Salt preparation
- Redox concepts
- Oxidation states
- Volumetric analysis / titration
- Titration calculations
- Qualitative analysis

后续可以继续扩展到更多 Chemistry topics，并为 Chinese 课程单独使用中文界面和中文内容。
